# Reading and support

Check the current section, topic, language and version before reading. Desktop rails and narrow-screen disclosures lead to the same destinations. Keep long signatures and code scrolling within their blocks, and keep focused controls and line targets visible below fixed headers.

Search is partitioned by language and version. No matches, loading and index failures are different states; retain a static directory on failure. Missing translations identify the source language and available routes instead of treating translated navigation as translated prose.

Reading settings control presentation such as theme, wrapping and line numbers. Persistence depends on the host's stated behavior. Settings do not change document identity, publication authority or version. Text, ordinary links and necessary directories remain available without scripts.

Identify each example's full name, license, source and scope. The API Portal and preference guide of BP/bp-docs-js-cookie are separate entries, not the product website or all demonstration projects.

## Contributing, licensing and feedback

For core tools, the website and manuals, see the [contribution guide](https://github.com/mandolin/HIA-Documentation#contributing) and the [main repository license](https://github.com/mandolin/HIA-Documentation/blob/main/LICENSE). Use [main repository issues](https://github.com/mandolin/HIA-Documentation/issues) for ordinary feedback. Include the full package name, actual version, public inputs, reproduction steps, and expected and actual results.

Send component feedback to the owning repository. Its root contains the applicable license and development guidance.

| Scope | Owning repository |
| --- | --- |
| JavaScript / JSDoc | [hia-jsdoc](https://github.com/mandolin/hia-jsdoc), [jsdoc-plugin-hia-sys](https://github.com/mandolin/jsdoc-plugin-hia-sys), [jsdoc-theme-hia](https://github.com/mandolin/jsdoc-theme-hia) |
| HTML, CSS and .NET | [hia-htmdoc](https://github.com/mandolin/hia-htmdoc), [hia-cssdoc](https://github.com/mandolin/hia-cssdoc), [hia-dotnetdoc](https://github.com/mandolin/hia-dotnetdoc) |
| JavaScript demonstration | [bp-docs-js-cookie](https://github.com/mandolin/bp-docs-js-cookie) |

For vulnerabilities in HIA Documentation Sys or an official component, sign in to GitHub and [report the vulnerability privately](https://github.com/mandolin/HIA-Documentation/security/advisories/new) to the main repository. Include the full package or repository name and the affected version. Follow each demonstration or third-party project's own reporting policy. Keep vulnerability details and sensitive data out of public issues. See the [security reporting policy](https://github.com/mandolin/HIA-Documentation/blob/main/SECURITY.md).
