# Read APIs from generated artifacts

HIA generates code documentation from actual artifacts; overview prose does not synthesize API signatures. Render the descriptions, signatures, parameters, type parameters, returns, exceptions, examples and provenance that the input actually contains. Do not invent absent semantics.

Choose the system documentation version, then identify the package, source revision and generator/theme. Core tools, JavaScript, HTML, CSS and .NET have distinct input chains. Similar presentation does not imply a common parser. Provide direct entries for both standalone JSDoc and the unified Portal.

Compare public package exports with actual generated symbols. Processing one domain fixture does not establish documentation coverage for the tool package itself, and an installed dependency is not automatically an extracted API.

Distinguish C#/XML application APIs from the JavaScript APIs of the DotNetDoc tools. Declare each generation scope and its unmapped entries.

For provenance, check the revision, authority, digest and range evidence. Keep API reading available without verified source. Do not relabel XML locations as C# locations or restore excluded external source links. Link manuals and generated references while retaining each package as the owner of its definitions.

## Generated reference entries

- [JavaScript documentation tool package API](https://mandolin.github.io/HIA-Documentation-API-JavaScript/en/) provides package interfaces for documentation runners, producers, plugins, specifications and themes, including configuration schemas and static array/descriptor data. Browse by full package name and original declaration. Search covers this site.
- [HTML documentation tool package API](https://mandolin.github.io/HIA-Documentation-API-HTML/en/) provides HTML parsing, documentation extraction, adaptation, source maps, Custom Elements Manifest conversion and runner/producer/specification interfaces, including current and legacy schemas, static declaration data and complete sources. Browse by full package name and original declaration. Search covers this site.
- [CSS documentation tool package API](https://mandolin.github.io/HIA-Documentation-API-CSS/en/) CSS parsing, documentation extraction, adaptation, source maps, design-token conversion and runner/producer/specification interfaces, including current and legacy schemas, static declaration data and complete sources. Browse by full package name and original declaration. Search covers this site.
- [DotNetDoc documentation tool package API](https://mandolin.github.io/HIA-Documentation-API-DotNetDoc/en/) JavaScript runtime and TypeScript declaration interfaces for six DotNetDoc documentation tool packages, covering C# source extraction, XML documentation extraction, adapters, runners, producers and specifications. Includes original bilingual documentation, signatures, sixteen current/legacy JSON resources, static declaration data, native maps and complete sources. Browse by full package name and original declaration. Search covers this site.
- [JSDoc configuration derivation evidence](https://mandolin.github.io/HIA-Documentation-Resources-JSDoc/derivation-evidence/en/) presents configuration derivation records, sources, digests and coverage per value. Each original artifact declares whether its evidence records actual production or static inference. Search covers the evidence partition.

- [HIA thirteen-core-package API · English](https://mandolin.github.io/HIA-Documentation-API/en/) · [Chinese](https://mandolin.github.io/HIA-Documentation-API/zh-CN/) provides modules from thirteen core packages and two JSON resources from the plugin development toolkit. Another 45 resources are listed by full name in [Resource reference partitions](../reference/#resource-reference-partitions), covering core and source schemas, TypeScript documentation, documentation profiles and business workflows. The reference manual also lists command paths. Satellite tool coverage follows each tool's documented scope.

- [HIA unified generated reference · English](../../../en/): existing public artifacts, including samples and tool references, without a claim of complete required-package coverage.
- [HIA unified generated reference · Chinese](../../../zh-CN/): retains the actual field locales in its inputs.
- [BP/bp-docs-js-cookie · API Portal](https://mandolin.github.io/bp-docs-js-cookie/): the first JavaScript demonstration project, separate from the product website.
- [Actual standalone JSDoc theme output](../../../jsdoc/index.en.html) presents the public theme module, class and method example generated by normal JSDoc, with native locale pages and admitted source excerpts. Complete tool-package APIs are available in the reference sites above.
- [Standalone JSDoc build guidance](https://github.com/mandolin/HIA-Documentation/blob/main/docs/published-jsdoc-usage.md) covers the runner, plugin, theme and configuration.
