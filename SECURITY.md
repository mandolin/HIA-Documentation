# Security Policy

HIA Documentation Sys is pre-1.0. Security fixes target the current `main` branch and the latest public npm versions of official packages.

## Report a vulnerability privately

Use the [private vulnerability report](https://github.com/mandolin/HIA-Documentation/security/advisories/new) in `mandolin/HIA-Documentation` for the main project and its official components. Sign in to GitHub and include the affected component's full package or repository name and version. The main repository maintainers coordinate triage with the component maintainers. Follow each demonstration or third-party project's own reporting policy.

Keep vulnerability details, credentials, private source code, and unpublished artifacts out of public issues. See the [full security policy](docs/security-policy.md) for the supported versions and reporting guidance.

## 私下报告漏洞

HIA Documentation Sys 主项目及正式组件统一通过主仓的[私下漏洞报告表单](https://github.com/mandolin/HIA-Documentation/security/advisories/new)接收安全报告。请登录 GitHub，注明受影响组件的完整包名或仓库名及版本，由主仓维护者协调处理。演示项目和第三方项目遵循各自的报告政策。

公开 Issues 仅用于普通问题。请勿在其中贴出漏洞细节、凭据、私有源码或未发布工件。支持版本与详细指引见[安全政策](docs/security-policy.md)。
